# 💻 Coding Pets Prompt

## Code Review Cat

```text
Create a cute pixel-art Codex desktop pet spritesheet.
The pet is a code review cat sitting beside a tiny laptop.
It holds a red review pen in the review state and shows a tiny bug icon in the failed state.
Include idle, running-left, running-right, waving, waiting, review, and failed states.
Use transparent background and consistent frame size.
```
