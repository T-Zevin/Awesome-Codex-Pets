## What Is This

`Awesome Codex Pets` is a curated resource list for Codex desktop pets.

It collects:

- pet galleries and download sites;
- open-source pet packs and related tools;
- installation and configuration notes;
- prompt ideas for making new pets;
- troubleshooting links and community references.

The main README is written in Chinese because this repository is intended as a Chinese-friendly entry point.

## Quick Start

Most custom Codex pets use this structure:

```text
pet-name/
├── pet.json
└── spritesheet.webp
```

See [docs/install.md](docs/install.md) for details.
