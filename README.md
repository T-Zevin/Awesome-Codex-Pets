## ✨ 这个仓库是什么

`Awesome Codex Pets` 是一个 Codex 桌宠资源导航仓库。

它不是单纯搬运宠物包，而是把和 Codex Pets 相关的资源整理成更容易查找的中文入口：

- 🧭 资源站点：Gallery、下载站、社区图鉴、目录站
- 📦 开源项目：宠物包、播放器、CLI、桌面应用、React 组件
- 🛠️ 使用教程：安装、配置、目录结构、常见问题
- 🧪 制作教程：`pet.json`、`spritesheet.webp`、动画状态、投稿模板
- 💡 Prompt 灵感：像素风、科研风、代码助手风、可爱桌宠风

## 🚀 快速开始

Codex 自定义桌宠通常由两个核心文件组成：

```text
pet-name/
├── pet.json
└── spritesheet.webp
```

一般使用流程：

1. 下载一个 Codex Pet 宠物包。
2. 解压后确认目录里有 `pet.json` 和 `spritesheet.webp`。
3. 放到你的 Codex pets 目录中。
4. 打开 Codex 的外观设置，选择对应宠物。
5. 在 Codex 里使用 `/pet` 唤醒桌宠。

详细教程见：[docs/install.md](docs/install.md)
